# Panel : ce qui a été fait

- 100 cartes acheteuses distribuées (seed 7) à partir de `customer.json`, pour les deux versions de l'offre.
- **v1** (`../panel-v1/`, offre d'origine : Essentiel 9,90 € solo, Duo 19,90 €, pas d'essai) : 20 acheteuses interrogées (P001–P020), **0 achat sur 20**.
- **v2** (`./`, offre corrigée dans `../offer.md` : Duo 9,90 €/mois pour deux ou 59 €/an, essai 14 jours quand les deux ont fait le test, rappel le soir, sources citées, satisfait ou remboursé, offre fondateurs 49 €/an) : 30 acheteuses interrogées (P001–P030, dont les 20 de la v1), **5 achats sur 30 (17 %)**.
- Le pack a été arrêté à 20 puis 30 acheteuses au lieu de 100 : les réponses étaient très répétitives et chaque acheteuse simulée coûte un appel de sous-agent. Les 70 cartes restantes sont listées comme « missing » par l'outil ; elles n'ont pas été interrogées. Le taux d'achat est calculé sur les réponses reçues.
- Acheteuses simulées, pas des clientes : le taux est une borne haute, les objections et les mots sont ce qu'il faut garder.
